Modal side sheet — filters (M2's flagship use)

Full height, right-anchored, 320px on desktop; on mobile it insets 48px from the top and 16px from the bottom (M2 modal specs) behind a visible scrim. Escape, scrim tap and the header ✕ all dismiss it.

Standard side sheet — persistent details panel

A plain <aside> — no scrim, no <dialog>, no library JS; the button just toggles the hidden attribute. Desktop/tablet only: below 600px M2 replaces it with the modal side sheet.

Filler — so the page has height to scroll

The standard sheet is fixed to the trailing edge, so content needs its own clearance — give the scroll container padding-right as wide as the sheet (this demo pads the footer when the panel is open).

Rows are the shared 48px .fl-option row — checkboxes and radios compose exactly as in dialogs, and whole-row checkbox toggles are <label class="fl-option">.

Fields and section labels ride .fl-sidesheet__group so the option rows can run full-bleed without negative margins.

Only vertical scrolling exists inside a side sheet (M2); the body slot scrolls while the header stays pinned.

The sheet pairs on the opposite edge from the nav drawer or rail (M2's placement rule) — left rail, right sheet.

The scrim is the shared 32% black (--fl-scrim) — visibly dimming the page behind a modal side sheet is M2's own Do/Don't rule.

Swipe-to-dismiss is a documented gap: scrim tap, the ✕ and Escape cover dismissal on every input.

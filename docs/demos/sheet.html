About Flint

Flint is a flat Material 2 library for building web apps with plain HTML — one stylesheet, one small script, no build step and no dependencies.

Surfaces are 1px-bordered cards, never shadows. State layers are flat fills at a shared duration. The density is 44px fields, not the 56dp Material default.

The modal layer is the native <dialog>: focus trap, inert background, Escape and top-layer stacking come from the platform, so flint.js stays small.

Bottom sheets share that layer — same scrim token, same focus protocol, same scroll lock, one rule of html:has(dialog[open]).

The initial height is capped at 50dvh (M2's rule). fl-sheet--full is the documented escape hatch for content that needs the whole screen — and it requires a close action, because the scrim alone can't be the way out.

There is no drag handle and no swipe-to-dismiss: a vertical drag fights the sheet's own scroll. Dismissal is scrim tap, Escape, the rows and the actions — all of them work.

Every component degrades honestly: without JavaScript the page renders and works; modal sheets simply stay closed until you open them.

Long content scrolls inside the body while the title and actions stay pinned — flexbox, not JavaScript.

Fields, buttons, lists and selection controls all compose inside sheets exactly as they do on a page.

Rows are 56px tall in sheets and 48px in dialogs — both are spec numbers, one shared .fl-option row with a height token per context.

The scrim is 32% black — the M2 value — and one token (--fl-scrim) covers sheet, dialog and drawer.

Everything above is a documented decision, not an accident — the docs say what deviates from Material 2 and why.

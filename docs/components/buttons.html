Buttons

Filled, outlined and text buttons with flat state layers — no shadows, no ripples, 40px touch targets.

Usage

Buttons trigger actions — never navigation between destinations (that is what the shells' tabs and nav rows are for). The three variants encode emphasis: one filled (primary) action per view, outline for important secondary actions, text for everything else.

Do use it when

  • There is one clear primary action in view — give it fl-btn--filled and everything else less weight.
  • The action sits inside a card, dialog content, or a form's action row (secondary link left, filled button right — the auth-card pattern).
  • Actions are toolbars of equals (Compose / Snooze / Archive) — use text buttons so nothing competes with the content.

Don't use it when

  • The element navigates to another destination — use a real link or a nav item; buttons that navigate confuse keyboard and screen-reader users.
  • You need icon-only actions in chrome (top bars, list rows) — that is fl-icon-btn, not a text button.
  • More than one filled button would appear in the same view — two primaries cancel each other out.

Anatomy

  1. 40px height — M2 touch-target size at every breakpoint; inline-flex centers the label.
  2. Filled — solid accent fill, surface-colored label; hover/active darken via the accent-hover/pressed tokens (a state layer without transparency).
  3. Outline — 1px border, accent label, hover takes the flat --fl-hover fill.
  4. Text — accent label, no fill until hover.

Behavior

  • State layers are fills, not shadows or ripples: filled darkens on hover and further on press; outline and text take the --fl-hover gray on hover and --fl-divider on press. Transitions run at --fl-dur/--fl-ease.
  • Variants combine with icons: put a fl-icon placeholder (or a real SVG) inside with 8px margin — the flex layout centers it. Icon sizes are not auto-adjusted inside fl-btn.
  • Adjacent pairs: the convention is text button left, filled right (Cancel / Confirm), right-aligned with an 8px gap — mirrors the auth-card action row.
  • Buttons are <button> or <a> — both get the styles; anchors should still only be used where the action really is a navigation-adjacent verb ("Create account").
  • Disabled is styled since 0.3: the native attribute gives a flat gray treatment — --fl-divider fill on filled, --fl-divider border/label on outline, --fl-disabled label on text. Don't rely on color alone to convey it; consider also dropping the button or explaining why in adjacent text.
  • Related controls: fl-icon-btn (40px rounded-square, for chrome) and fl-fab (56px fixed circle docked above the tab bar) — see the bottom-nav shell page.

Accessibility

  • Buttons are real <button> elements — Enter/Space activation, form submission, and focus are platform behavior; nothing is reimplemented.
  • Labels are visible text; don't ship icon-only text buttons — if there is no room for text, fl-icon-btn + aria-label is the pattern.
  • :focus-visible gets the 2px accent ring globally (on the accent-filled button the ring still reads via its offset).
  • State is conveyed by color only in hover/press — which is fine, because those states are pointer-specific; the *enabled/disabled* distinction must not be color-only, so when a button disables, also update adjacent copy or remove the action rather than relying on the gray fill.
  • Buttons that toggle (e.g. "Follow"/"Following") should carry aria-pressed.

Code

Two files bring the library in; the markup below covers the variants.

<link rel="stylesheet" href="css/flint.css">
<script src="js/flint.js" defer></script>
<!-- Variants: one filled primary per view -->
<button class="fl-btn fl-btn--filled">Compose</button>
<button class="fl-btn fl-btn--outline">Snooze</button>
<button class="fl-btn fl-btn--text">Archive</button>

<!-- With a leading icon placeholder -->
<button class="fl-btn fl-btn--filled">
  <span class="fl-icon" aria-hidden="true" style="margin-right:8px;"></span>
  Add item
</button>

<!-- Action row (auth-card convention) -->
<div style="display:flex; gap:8px; justify-content:flex-end;">
  <button class="fl-btn fl-btn--text">Cancel</button>
  <button class="fl-btn fl-btn--filled">Confirm</button>
</div>

<!-- Disabled: native attribute; gray fill (filled) / gray border+label (outline) -->
<button class="fl-btn fl-btn--filled" disabled>Unavailable</button>

<!-- Icon-only chrome: not a text button — see fl-icon-btn -->
<button class="fl-icon-btn" aria-label="More options">
  <span class="fl-icon" aria-hidden="true"></span>
</button>

Theming

Everything is a CSS custom property on :root — override inline or in your own stylesheet, no rebuild:

TokenAffects
--fl-accentFilled fill; outline/text label color
--fl-accent-hoverFilled hover fill
--fl-accent-pressedFilled active fill
--fl-hoverOutline/text hover fill
--fl-dividerOutline/text press fill; disabled filled fill and outline border
--fl-disabledDisabled label color
--fl-borderOutline variant border
--fl-radiusCorner radius (4px)
--fl-fs-bodyLabel size (14px)
 
:root {
  --fl-accent: #188038;          /* green Google */
  --fl-accent-hover: #166b30;
  --fl-accent-pressed: #135626;
}

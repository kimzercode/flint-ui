Drawer shell

App frame with a permanent 280px navigation column on desktop and an off-canvas drawer over a scrim on mobile.

Usage

The drawer shell is for app-like products with persistent navigation — the Gmail-2020 pattern: a permanent inset nav column on wide screens, the same markup collapsing to an off-canvas drawer on phones.

Do use it when

  • Your product has more destinations than a bottom bar can hold, and they deserve permanent visibility on desktop.
  • You want one markup that is a nav column on desktop and a drawer on mobile, with no separate mobile template.
  • The content is a feed/workspace (mail, docs, admin) rather than a flow.

Don't use it when

  • The page is a marketing or landing page — no shell is needed.
  • You only have 3–5 top-level destinations — the bottom-nav shell is simpler and more mobile-native.
  • Navigation must stay visible while scrolling on phones; drawers are opened on demand there.

Anatomy

  1. Top app bar — stays fixed; the column scrolls, not the bar.
  2. Drawer column — 280px permanent on wide screens; part of the grid, not a floating panel.
  3. Nav rows — real links/buttons; the current destination gets the inset tinted pill via aria-current="page".
  4. Content — the only scrolling area; capped by --fl-content-max.
  5. Scrim (mobile only) — under the drawer when it slides in; tap or Escape closes.

Behavior

  • ≥905px: the drawer is a permanent 280px grid column. The top bar spans both columns; only the content scrolls.
  • <905px: the drawer is fixed off-canvas and slides in over a scrim. flint.js toggles a fl-drawer-open class on <body> and syncs aria-expanded on the open button.
  • Closing: scrim click, the close button, or Escape.
  • Manual control: flint.drawer(true) / flint.drawer(false).
  • Selection: rows key off aria-current="page"; flint.js reflects it on click inside any [data-fl-nav] container. With server routing you set it yourself and skip JS entirely.
  • Links over buttons: rows can be <a href> — navigation still happens; the selected state is reflected.

Accessibility

  • Open/close buttons need aria-label, aria-controls, and an initial aria-expanded="false" — flint.js keeps them in sync.
  • The nav has aria-label="Primary"; the drawer has aria-label so screen readers announce it as a landmark.
  • The scrim is aria-hidden="true" — it is decoration, not a control.
  • Rows are real <a>/<button> elements — keyboard support is built in; :focus-visible gets the accent ring.
  • Icon placeholders and badges are aria-hidden; put meaning in the row text or the button label.
  • Include viewport-fit=cover in your meta viewport for safe-area support.

Code

Two files bring the library in; the markup below is the whole drawer shell.

<link rel="stylesheet" href="css/flint.css">
<script src="js/flint.js" defer></script>
<body class="fl-reset">
<div class="fl-shell-drawer">

  <header class="fl-top-bar">
    <button class="fl-icon-btn fl-only-mobile" data-fl-drawer-open
            aria-label="Open navigation menu" aria-controls="my-drawer"
            aria-expanded="false">
      <span class="fl-icon"></span>
    </button>
    <h1 class="fl-top-bar__title">App name</h1>
  </header>

  <aside class="fl-drawer" id="my-drawer">
    <div class="fl-drawer__header">
      App name
      <button class="fl-icon-btn fl-only-mobile" data-fl-drawer-close
              aria-label="Close navigation menu">
        <span class="fl-icon"></span>
      </button>
    </div>
    <nav class="fl-nav" data-fl-nav aria-label="Primary">
      <a class="fl-nav-item" aria-current="page" href="#"><span class="fl-icon"></span>Inbox<span class="fl-badge">3</span></a>
      <a class="fl-nav-item" href="#"><span class="fl-icon"></span>Sent</a>
    </nav>
    <hr class="fl-divider">
    <div class="fl-drawer__footer">…account row…</div>
  </aside>

  <div class="fl-scrim" data-fl-drawer-close aria-hidden="true"></div>
  <main class="fl-content">…</main>
</div>
</body>

Theming

Everything is a CSS custom property on :root — override inline or in your own stylesheet, no rebuild:

TokenAffects
--fl-tintSelected nav row pill fill
--fl-accentSelected row icon/text tint, focus ring
--fl-hoverRow hover fill
--fl-borderDrawer column divider (replaces shadows)
--fl-topbar-hTop bar height
--fl-content-maxMax content column width on desktop
--fl-dur / --fl-easeDrawer slide-in motion
 
:root {
  --fl-accent: #188038;    /* green Google */
  --fl-tint: #e6f4ea;
}

Lists

Single-, two- and three-line rows with icon/avatar leading zones and a trailing meta zone — the Gmail-2020 list.

Usage

Lists are the workhorse content component — mail, contacts, settings, files. Flint's list follows the Gmail-2020 spec: fixed-height rows with a leading zone (24px icon or 40px avatar), a text block, and a trailing meta zone. Rows separate by spacing, not rules.

Do use it when

  • Content is a collection of peer items — messages, people, documents, settings.
  • Rows repeat the same structure with varying text and metadata.
  • You want selectable rows that fit a shell (selected rows take the tint fill, like Gmail's mail list).

Don't use it when

  • Items are heterogeneous content blocks — use cards.
  • Rows need to expand/collapse (accordions) — not in the library yet.
  • You need multi-select checkboxes — planned; the current meta zone holds one control, but selection is single via aria-current.

Anatomy

  1. Leading zone — 24px icon or 40px avatar (initials text, or an <img> cropped by object-fit).
  2. Selected row — tint fill via aria-current="page"; content rows keep neutral text (unlike nav items, which also take the accent).
  3. 72dp keyline — the 16px gap after a 40px avatar lands text on the spec keyline automatically.
  4. Meta zone — trailing actions, badges, or secondary text (timestamps). Badges sit inline here.
  5. Three-line rows — body text wraps to two lines, then clamps.
  6. Dense variant — 40px rows (60/76px for two/three-line) for data-heavy screens.

Row types

RowHeightLeadingUse for
fl-list-item48pxiconSettings, simple rows
--two-line72pxicon or avatarContacts, mail previews
--three-line88pxiconMessages with body text
fl-list--dense40/60/76pxicon preferredData-heavy screens
fl-list--dividers——Opt-in 1px rules between rows

Dividers are opt-in because 2020 Google lists separate rows by spacing; rules appear between sections, not rows. Selected rows (aria-current="page") take the tint fill with neutral text — unlike nav items, which also take the accent.

Accessibility

  • The list is a real <ul class="fl-list"> — screen readers get item counts for free.
  • Rows with nested controls: make the row a plain <li class="fl-list-item"> and put the action in the meta zone — only the control is the target. Rows that navigate: make the row itself an <a class="fl-list-item"> — then hover/active/selected all work on the row, and don't nest controls in its meta zone.
  • Selected rows carry aria-current="page"; disabled rows carry aria-disabled="true" (pointer events are also suppressed).
  • Icons and badges are aria-hidden; icon buttons in the meta zone need specific labels ("More options for Q3 roadmap", not "More").
  • Timestamps and counts in the meta zone are visible text — no SR-only duplication needed.

Code

Two files bring the library in; below are the three core row patterns.

<link rel="stylesheet" href="css/flint.css">
<script src="js/flint.js" defer></script>
<!-- Two-line row with avatar and trailing action (plain li: only the
     icon button is the target) -->
<ul class="fl-list">
  <li class="fl-list-item fl-list-item--two-line">
    <span class="fl-list-item__avatar" aria-hidden="true">AK</span>
    <span class="fl-list-item__text">
      <span class="fl-list-item__title">Aisha Karim</span>
      <span class="fl-list-item__sub">aisha@example.com</span>
    </span>
    <span class="fl-list-item__meta">
      <button class="fl-icon-btn" aria-label="Message Aisha">
        <span class="fl-icon" aria-hidden="true"></span>
      </button>
    </span>
  </li>
</ul>

<!-- Three-line row: body text wraps to two lines, then clamps -->
<ul class="fl-list">
  <li class="fl-list-item fl-list-item--three-line">
    <span class="fl-list-item__icon"><span class="fl-icon" aria-hidden="true"></span></span>
    <span class="fl-list-item__text">
      <span class="fl-list-item__title">Sprint 14 retro notes</span>
      <span class="fl-list-item__sub">Body text wraps to two lines…</span>
    </span>
    <span class="fl-list-item__meta">Sep 30</span>
  </li>
</ul>

<!-- Interactive row: the whole row is the target -->
<ul class="fl-list">
  <li>
    <a class="fl-list-item fl-list-item--two-line" href="#" aria-current="page">
      <span class="fl-list-item__avatar" aria-hidden="true">HK</span>
      <span class="fl-list-item__text">
        <span class="fl-list-item__title">hakim@example.com</span>
        <span class="fl-list-item__sub">Personal</span>
      </span>
      <span class="fl-list-item__meta">Current</span>
    </a>
  </li>
</ul>

Theming

Everything is a CSS custom property on :root — override inline or in your own stylesheet, no rebuild:

TokenAffects
--fl-tintSelected row fill
--fl-hoverRow hover fill
--fl-dividerOpt-in divider color
--fl-icon-phAvatar placeholder fill
--fl-text-secondarySub text, meta text
--fl-fs-captionSub/meta font size
 
:root {
  --fl-tint: #e6f4ea;   /* rows tint green when selected */
}

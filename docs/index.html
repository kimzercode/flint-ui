Components

Flint UI is a set of interactive building blocks for flat, Google-flavored app shells — pure CSS, ~50 lines of vanilla JS, framework-agnostic.

Browse the components below. Every page pairs live examples rendered with real Flint markup with copy-pasteable code.

  • Auth shell Centered 400px column with an outlined-field card for sign-in screens.
  • Bottom-nav shell App frame with a top bar and 3–5 destinations pinned to the bottom.
  • Drawer shell App frame with a permanent 280px nav column on desktop, off-canvas on mobile.
  • Lists Single/two/three-line content rows in the Gmail-2020 style.
  • Rail shell App frame that is a bottom nav on mobile and an 80px icon rail on desktop.
  • Planned Buttons Filled, outlined and text buttons with flat state layers.
  • Planned Cards Outlined content containers, no shadows.
  • Planned Dialog Modal dialog over the existing scrim, with focus handling.
  • Planned Bottom sheet Sheet docked above the tab bar, reusing the scrim.
